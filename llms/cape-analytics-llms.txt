# Cape Analytics

> Cape Analytics (now part of Moody's) is a geospatial property intelligence provider that applies computer vision and machine learning to aerial and satellite imagery, property records, and other data sources to produce inspection-quality condition and characteristic data for 100M+ residential and commercial structures across the US and Canada. Insights are delivered to insurers, lenders, and real estate investors via API, bulk/batch files, an Automated Property Condition Report (aPCR), and a customer web portal, as well as through platforms such as Guidewire and Duck Creek. There is no public self-service developer portal or open API specification; API access is provisioned through a gated onboarding flow.
